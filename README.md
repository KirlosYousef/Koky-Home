# Koky-Home

A standalone static landing page for the Koky iOS app. This repository contains only the website, its legal pages, and the images used by those pages.

## GitHub Pages

In the repository settings, open **Pages** and publish from the `main` branch root. The site uses relative links and assets, so it works at both the repository URL and a future custom domain.

- Landing page: `/`
- Privacy policy: `/privacy/`
- Terms and conditions: `/terms/`
